# Trash Mboa — Urban Waste Management App

> Civic-tech web application for reporting and tracking urban waste collection in Douala, Cameroon — connecting citizens and municipal services.

---

## Overview

Trash Mboa tackles a real urban challenge in Douala: inefficient waste collection and lack of communication between citizens and municipal services. Citizens can report dump sites, track collection schedules in their neighborhood, and hold services accountable through a public dashboard.

---

## Key Features

- **Incident Reporting** — Geolocated reports with photo upload
- **Collection Schedule** — Neighborhood-level collection calendar
- **Status Tracking** — Follow-up on reported incidents
- **Public Dashboard** — City-wide waste management stats
- **Notifications** — SMS/email alerts for collection day

## Getting Started

```bash
git clone https://github.com/styland-digital/trash-mboa.git
cd trash-mboa
npm install
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
